## Why this exists

I have spent **8+ years** shipping software with **React.js**, **React Native**, and **Node.js**. That path includes high-traffic campaigns, corporate platforms, and products where performance, SEO, and accessibility actually matter.

This site is the short version of that story: a dark, focused interface with bilingual-plus content, detailed project pages, and a timeline of real work.

## What you will find

- **Home** — a concise intro and a direct path into the rest of the site
- **About** — how I work and the kind of problems I like to solve
- **Skills** — frontend, mobile, backend, and the tools I use every day
- **Projects** — selected work with galleries, stack tags, and deep-dive pages
- **Experience** — roles, impact, and the technologies behind each one
- **Education** — academic background and highlights
- **Contact** — the fastest way to start a conversation
- **Soft Skills** and **Family** — a little more context beyond the résumé

Switch the language anytime. The UI is available in **Portuguese**, **English**, and **Spanish**.

## Built with

| Layer | Stack |
| --- | --- |
| UI | React 19, TypeScript, styled-components |
| Routing | TanStack Router |
| i18n | i18next |
| Tooling | Vite 7, ESLint |
| Delivery | GitHub Actions → GitHub Pages |

Every push to `main` builds the app and publishes it automatically.

## Run it locally

```bash
npm install
npm run dev
```

The app starts at `http://localhost:5173`.

```bash
npm run build    # production build
npm run preview  # preview the production bundle
npm run lint     # lint the source
```
